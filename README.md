# AL_Learning — Data Science & Computer Vision Journey

## About This Repository

This is my personal learning roadmap and portfolio for building skills in **Data Science** and **Computer Vision**. I'm focusing on Python, machine learning, deep learning, and MLOps while working on a real-world project: detecting early signs of metal toxicity in aquatic plants.

## My Project

**Plant Stress Detection Using Computer Vision**

I'm building an end-to-end pipeline that uses:
- **Object Detection** (YOLO, RF-DETR) to identify plant fronds/leaflets
- **SAHI** (Slicing Aided Hyper Inference) to detect small objects in large microscopy images
- **Segmentation** to measure plant size and growth over time
- **Colorimetric Analysis** to detect stress indicators
- **Time-Series Analysis** to track changes across image collections
- **VLM/LLM Integration** (future) for automated anomaly description
