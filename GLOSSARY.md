# Glossary

This glossary defines key terms used throughout the learning roadmap. It is devoid of implementation details — it exists to ensure shared vocabulary.

## Core Concepts

**Data Scientist** — A role that combines programming, statistics, and domain expertise to extract insights from data and build predictive models.

**Computer Vision (CV)** — A field of AI that enables machines to interpret and understand visual information from images and videos.

**Object Detection** — A CV task that identifies and locates objects within an image, typically with bounding boxes.

**Image Segmentation** — A CV task that classifies each pixel in an image, enabling precise object boundaries and size measurements.

**Transfer Learning** — A technique where a model pre-trained on a large dataset is fine-tuned for a specific task, reducing the need for large amounts of task-specific data.

**Data Augmentation** — Techniques that artificially increase dataset size by applying transformations (flips, rotations, color shifts) to existing images.

**SAHI (Slicing Aided Hyper Inference)** — A technique that slices large images into smaller patches for inference, enabling detection of small objects that would be missed if the image were scaled down.

**MLOps** — Practices and tools for deploying, monitoring, and maintaining machine learning models in production.

**VLM (Vision-Language Model)** — A multimodal AI model that can understand both images and text, enabling tasks like image captioning and visual question answering.

**LLM (Large Language Model)** — A text-based AI model trained on massive datasets, capable of understanding and generating human-like text.

## Technical Terms

**YOLO (You Only Look Once)** — A real-time object detection architecture that processes images in a single pass.

**RF-DETR** — A detection transformer model combining the strengths of DETR (DEtection TRansformer) with improved efficiency.

**CNN (Convolutional Neural Network)** — A deep learning architecture designed for processing grid-like data such as images.

**PyTorch** — An open-source deep learning framework preferred for research and CV applications.

**scikit-learn** — A Python library for traditional machine learning algorithms (classification, regression, clustering).

**pandas** — A Python library for data manipulation and analysis.

**NumPy** — A Python library for numerical computing with arrays and matrices.

**OpenCV** — A library for computer vision tasks (image processing, feature detection, etc.).

**Streamlit** — A Python framework for building interactive web applications and dashboards.

**Docker** — A platform for containerizing applications, ensuring consistent environments across development and production.

**SQL (Structured Query Language)** — A language for managing and querying relational databases.

**Git** — A version control system for tracking changes in code.

**GitHub** — A platform for hosting and collaborating on Git repositories.

## Domain Terms

**Ecotoxicology** — The study of the effects of toxic chemicals on biological organisms, especially within ecosystems.

**Frond** — A large, divided leaf, typically found in ferns and some aquatic plants.

**Leaflet** — A small leaf-like structure that is part of a compound leaf.

**Colorimetric Analysis** — The measurement of color intensity to determine the concentration of a substance or the degree of a reaction.

**Stress Response (Plant)** — The set of physiological and morphological changes a plant undergoes in response to adverse environmental conditions (e.g., metal toxicity).

**Time-Series Analysis** — The analysis of data points collected over time to identify trends, patterns, and anomalies.
